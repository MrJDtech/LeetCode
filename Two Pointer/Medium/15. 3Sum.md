# [125. Valid Palindrome](https://leetcode.com/problems/valid-palindrome)

## Description

Given a string `s`, determine whether it is a palindrome after:

- Converting all uppercase letters into lowercase.
- Removing all non-alphanumeric characters.

Return `true` if it is a palindrome, otherwise return `false`.

### Example 1

**Input:**

```text
s = "A man, a plan, a canal: Panama"
```

**Output:**

```text
true
```

**Explanation:**

After removing non-alphanumeric characters and converting to lowercase:

```text
"amanaplanacanalpanama"
```

This reads the same forward and backward.

### Example 2

**Input:**

```text
s = "race a car"
```

**Output:**

```text
false
```

### Example 3

**Input:**

```text
s = " "
```

**Output:**

```text
true
```

## Solution

### Solution 1: StringBuilder + Two Pointer Comparison

#### Intuition

Since only lowercase letters and digits should be considered, first build a new string containing only valid characters in lowercase.

Once the cleaned string is ready, compare characters from the beginning and the end. If every corresponding pair matches, the string is a palindrome.

#### Algorithm

1. Create an empty `StringBuilder`.
2. Traverse every character in the input string.
3. If the character is alphanumeric:
   - Convert it to lowercase.
   - Append it to the `StringBuilder`.
4. Convert the `StringBuilder` into a string.
5. Compare the first and last characters, moving towards the center.
6. If any pair differs, return `false`.
7. If all pairs match, return `true`.

#### Java

```java
class Solution {
    public boolean isPalindrome(String s) {
        StringBuilder Sb = new StringBuilder();

        for (char x : s.toCharArray()) {
            if (Character.isLetterOrDigit(x)) {
                Sb.append(Character.toLowerCase(x));
            }
        }

        String A = Sb.toString();

        for (int i = 0; i < A.length(); i++) {
            if (A.charAt(i) != A.charAt(A.length() - 1 - i)) {
                return false;
            }
        }

        return true;
    }
}
```

#### Dry Run

**Input**

```text
s = "A man, a plan, a canal: Panama"
```

**After removing non-alphanumeric characters and converting to lowercase**

```text
amanaplanacanalpanama
```

Comparison:

| Left | Right | Result |
|------|-------|--------|
| a | a | ✔ |
| m | m | ✔ |
| a | a | ✔ |
| n | n | ✔ |
| ... | ... | ✔ |

No mismatch is found, so the answer is:

```text
true
```

#### Complexity Analysis

- **Time Complexity:** **O(n)**  
  - One traversal to build the cleaned string.
  - Another traversal to compare characters.

- **Space Complexity:** **O(n)**  
  - Extra space is used to store the cleaned string.

#### Key Points

- Uses `Character.isLetterOrDigit()` to ignore special characters.
- Uses `Character.toLowerCase()` for case-insensitive comparison.
- Compares characters from both ends to determine whether the cleaned string is a palindrome.
